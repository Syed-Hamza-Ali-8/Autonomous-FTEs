# Data Scientist - Scoring Rubric

## Must-Have Requirements
- 3+ years data science/analytics experience
- Strong Python and SQL skills
- Experience with statistical analysis and modeling
- Experience with data visualization tools
- Strong communication skills

## Nice-to-Have
- Advanced degree in quantitative field
- Experience with deep learning
- Big data tools (Spark, Hadoop)
- A/B testing and experimentation

## Scoring Breakout
- Skills & Technical Knowledge: 35 points
- Experience & Track Record: 25 points
- Project Impact: 20 points
- Communication: 10 points
- Bonuses: 10 points
