# Senior Backend Engineer - Scoring Rubric

## Must-Have Requirements (Pass/Fail)
- 5+ years of professional backend development experience
- Strong proficiency in Python or similar backend language
- Experience with distributed systems and microservices
- Database design and optimization experience
- RESTful API design and implementation

## Scoring Criteria (0-10 scale for each)

### Technical Skills (40%)
- **Backend Languages**: Python, Go, Java, Node.js expertise
- **Frameworks**: FastAPI, Django, Flask, Express, Spring Boot
- **Databases**: PostgreSQL, MySQL, MongoDB, Redis
- **Message Queues**: RabbitMQ, Kafka, Redis Streams
- **Cloud Platforms**: AWS, GCP, Azure experience

### System Design (30%)
- Distributed systems architecture
- Microservices design patterns
- Scalability and performance optimization
- Caching strategies
- API design and versioning

### Problem Solving (20%)
- Algorithm and data structure knowledge
- Debugging and troubleshooting skills
- Code quality and best practices
- Testing strategies (unit, integration, e2e)

### Communication & Collaboration (10%)
- Technical documentation skills
- Team collaboration experience
- Code review participation
- Mentoring junior developers

## Screening Questions
1. Describe your experience building and scaling distributed systems. What challenges did you face and how did you overcome them?
2. Walk me through your approach to designing a RESTful API for a high-traffic application. What considerations do you prioritize?
3. Tell me about a complex performance issue you debugged. What tools and techniques did you use?
4. How do you ensure code quality in a fast-paced development environment?
5. Describe your experience with database optimization. What strategies have you used to improve query performance?

## Red Flags
- Less than 3 years of backend experience
- No experience with production systems
- Poor communication skills
- No testing experience
- Lack of system design knowledge
- Job hopping (multiple jobs < 1 year)
- No experience with version control

## Ideal Candidate Profile
- 7+ years of backend development
- Led or architected distributed systems
- Strong Python and async programming
- Experience with high-scale systems (1M+ requests/day)
- Open source contributions
- Technical blog or speaking experience
- Mentoring experience
