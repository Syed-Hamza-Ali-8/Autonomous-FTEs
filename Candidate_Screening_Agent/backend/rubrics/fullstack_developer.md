# Full Stack Developer - Scoring Rubric

## Must-Have Requirements (Pass/Fail)
- 3+ years of professional full-stack development experience
- Proficiency in both frontend (React/Next.js) and backend (Node.js/Python) technologies
- Experience with database design and API development
- Understanding of web fundamentals (HTTP, REST, authentication)

## Scoring Criteria (0-10 scale for each)

### Frontend Skills (30%)
- React.js / Next.js expertise
- TypeScript proficiency
- UI/UX implementation (CSS, Tailwind, responsive design)
- State management (Redux, Context, Zustand)
- Performance optimization

### Backend Skills (30%)
- Node.js / Express.js or Python / FastAPI
- RESTful API design
- Database experience (PostgreSQL, MongoDB)
- Authentication & authorization (JWT, OAuth)
- API integration & third-party services

### DevOps & Deployment (20%)
- Git version control
- CI/CD pipelines
- Cloud platforms (AWS, Vercel, Render)
- Docker / containerization
- Monitoring & logging

### Communication & Collaboration (20%)
- Technical documentation
- Team collaboration
- Code review practices
- Agile/Scrum experience

## Screening Questions
1. Describe a full-stack application you built from scratch. What technologies did you use and why?
2. How do you approach designing a responsive, accessible user interface?
3. Tell me about a challenging API integration you implemented. What issues did you face?
4. How do you handle state management in complex frontend applications?
5. Describe your experience deploying and maintaining production applications.

## Red Flags
- Less than 1 year of professional development experience
- No experience with both frontend and backend
- No version control experience
- No testing experience
- Cannot explain basic web architecture concepts

## Ideal Candidate Profile
- 5+ years of full-stack development
- Strong portfolio of shipped products
- Experience with modern JavaScript frameworks
- Comfortable with both SQL and NoSQL databases
- Has led or owned features end-to-end
- Open source contributions or technical blog
